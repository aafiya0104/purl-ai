# ai-core

Owner: Aafiya

The AI harness: search layer, optimization layer, and routing layer. This is where the pipeline's actual intelligence lives, from implementation through production.

## Tech stack

- Python 3.11+
- FastAPI (API layer)
- Ollama (local model runtime)
- ChromaDB (vector cache)
- sentence-transformers (embeddings)
- requests (search API calls)

Implementation is added stepwise, layer by layer. This folder is currently a blank template.
